## Deployment to GitHub Pages + Custom Domain (earthquake.ssgpt6.com)

### Quick Setup (5 minutes)

1. **Create the Repository**
   - Go to https://github.com/new
   - Repository name: `earthquake.ssgpt6.com`
   - Visibility: **Public**
   - Do **NOT** initialize with README, .gitignore, or license (we will push everything)

2. **Push these files**
   ```bash
   git clone https://github.com/shanta4100/earthquake.ssgpt6.com.git
   cd earthquake.ssgpt6.com
   # copy or move the generated index.html, CNAME, and this README into the folder
   git add .
   git commit -m "Initial sovereign earthquake intelligence platform"
   git push -u origin main
   ```

3. **Enable GitHub Pages**
   - Repo → Settings → Pages
   - Source: **Deploy from a branch**
   - Branch: `main` / `(root)`
   - Save

4. **Configure Custom Domain**
   - In the same Pages settings, enter `earthquake.ssgpt6.com` as custom domain
   - GitHub will create a `CNAME` file automatically (we also included one)
   - **DNS Configuration** (at your domain registrar for ssgpt6.com):
     - Create a `CNAME` record:
       - Host: `earthquake`
       - Value: `shanta4100.github.io`
     - Or use GitHub's recommended A records for apex + subdomain (see GitHub docs)

5. **HTTPS**
   - GitHub Pages will automatically provision a certificate for your custom domain (may take a few minutes).
