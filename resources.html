MVP modules, APIs, and rollout priorities

This page keeps the requested deliverables visible while the static platform demo proves the dashboard, accessibility, and navigation experience in the browser.

Demonstrated browser capabilities

  • Web Speech API for command listening and spoken status updates.
  • Geolocation API for GPS context and nearby landmark messaging.
  • navigator.vibrate() patterns for haptic route alerts on supported devices.
  • ARIA live regions, skip links, and focus states for assistive technology support.

Chicago navigation pilot data sources

CTA transit status

Use transit arrivals and stop accessibility metadata to announce nearby rail or bus options.

Map providers

Connect Google Maps or Mapbox for cross-street, sidewalk, and reroute context when the production stack is enabled.

Accessibility signals

Log crosswalk observations, construction alerts, and hazard notes through Research OS™ workflows.

Implementation priorities

  1. Secure Gateway & tenant-aware authentication

  3. Voice Hub command orchestration
  4. Chicago navigation pilot
  5. Financial OS™ educational module

Suggested backend objects

  • Modules: OS selection, status, preference profile, feature flags

  • Navigation logs: route requests, landmarks, haptic events, accessibility reports
